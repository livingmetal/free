# 월급 타이머 1.4.0

개인용 Android 네이티브 급여 타이머입니다. Kotlin / Jetpack Compose로 구현되며 INTERNET 권한이 없습니다.

## 기능

- **다크 모드**: 시스템 / 라이트 / 다크 테마 선택 및 상단 즉시 전환. 앱을 다시 열어도 설정 유지.
- **오늘 / 이번 달**: 기본급·추가근무·지급 보너스 분리, 누적 환산액, 예정 합계, 진행률, 급여일 D-Day.
- **근무 달력**: 날짜별 추가 시수, 배율, 휴무, 메모, 보너스 기록. 토요일·일요일도 입력 가능.
- **휴대폰 캘린더 연결**: 사용자가 READ_CALENDAR를 허용한 경우에만 Calendar Provider의 보이는 일정을 읽어 표시. 반복 일정과 종일 일정 지원. 읽은 일정은 저장·전송하지 않고 급여에 자동 반영하지 않음.
- **외부 달력에 일정 추가**: 캘린더 앱에서 사용자가 확인 후 저장. 연봉이나 보너스 금액은 외부 캘린더에 전달하지 않음.
- **보너스**: 지급일, 이름, 금액, 지급 완료/예정 구분. 수정·삭제 가능.
- **연간 보기**: 연간 누적·예정 합계, 12개월별 내역, 추가 시수와 보너스 목록.

## 설치와 기존 버전

패키지 `com.livingmetal.salarytimer.personal`, versionName `1.4.0`, versionCode `14`, minSdk `26`, targetSdk `35`.

배포 APK는 v1.3.0의 개인 서명키를 그대로 사용합니다. 기존 v1.3.0을 삭제하지 않고 업데이트하는 구성입니다. 이전 SharedPreferences 설정은 새 저장 형식으로 읽어오며 기존 3D 돈주머니 아이콘도 유지합니다.

아주 초기 v1.0~v1.2 디버그 앱은 패키지가 다릅니다. 그 앱의 데이터를 별도 패키지에서 자동으로 가져오는 기능은 없습니다.

삼성 실기기 검증을 의미하지 않으며, 회사 관리 정책과 기기 보안 설정은 별도로 적용됩니다.

## 사용 방법

1. 설정에서 연봉, 급여일, 출퇴근/휴게시간을 저장합니다. 별도로 입력할 보너스는 연봉에서 제외하여 중복을 피합니다.
2. 달력에서 토/일 또는 원하는 날짜를 선택하고 **근무 / 주말 시수 입력**을 누릅니다. `4.5`처럼 소수 시간 입력 가능. 회사 지급 기준에 맞게 시급과 배율을 직접 설정합니다.
3. 보너스 입력에서 날짜·금액을 저장합니다. 지급 완료인 오늘/과거 금액만 누적되고 예정 금액은 예정 합계에만 표시합니다.
4. 캘린더 연결은 **설정 > 휴대폰 일정 표시**에서 선택합니다. 권한을 거부해도 급여 타이머와 근무 달력은 사용할 수 있습니다.
5. 연간 탭의 월별 행을 누르면 해당 월 달력으로 이동합니다.

## 계산 기준

기본급 = 연봉 / 12. 매월 1일~말일의 월~금 실근무시간에 나눠 배분합니다. 오늘·월간·연간은 동일한 기준을 사용합니다.

휴무로 지정한 평일은 배분시간에서 제외하지만 월 기본급을 삭감하지는 않습니다. 모든 근무일이 휴무이면 날짜/시간 비율로 배분합니다.

추가근무 = 입력 시수 × 추가근무 시급 × 입력 배율. 지정 시급이 0이면 해당 월의 기본급 환산 시급을 씁니다. 오늘·과거 날짜는 저장 즉시 누적, 미래 날짜는 예정 합계에만 반영합니다. 법정 가산율을 자동 판정하는 기능은 아닙니다.

보너스는 지급일이 오늘/과거이고 지급 완료로 기록된 경우에만 누적에 반영합니다. 연봉에 포함된 금액을 보너스에 다시 입력하면 중복됩니다.

공휴일 자동 제외, 세금, 은행 휴일 급여일 이동, 야간 교대근무는 지원하지 않습니다. 공휴일/연차는 달력에서 휴무로 직접 지정합니다. 급여일은 D-Day 표시용이며 누적 구간은 급여일 주기가 아닌 달력 월입니다. 현재 설정을 바꾸면 과거 환산액도 다시 계산됩니다. 실제 입금 잔액이나 급여명세 이력이 아닌 참고용입니다.

## 테스트 및 빌드

- 18개 계산 단위 테스트: 근무시간·점심시간, 주말, 휴무, 월간/일간 일치, 보너스, 연간, 윤년, 잘못된 입력 등.
- Android 16에서 6개 기능 테스트: 다크 모드 유지, 기존 설정 읽기, 주말 시수/보너스 입력, 달력/연간 화면, 입력 검증, 실제 Calendar Provider 읽기.
- 기본 CI는 테스트를 통과한 **미서명 release APK**를 생성합니다. 미서명 파일은 설치용이 아닙니다.
- 최종 배포물은 기기 소유자의 기존 개인키로 로컬 서명한 뒤 별도 워크플로에서 정확히 같은 APK를 재구성하여 서명·정렬·v1.3에서 업데이트 설치를 검증합니다.
- `release/v14-recipe`에는 공개 ZIP 메타데이터와 APK 서명 바이트만 있습니다. 개인키 또는 암호는 없습니다. 소스/결과 SHA-256을 검사하며 다른 빌드에는 적용할 수 없습니다.

최종 v1.4.0 APK SHA-256:
`7f0672ef7111624724656f9e10bac595c26e942d870527271a277e6203f9a189`

서명 인증서 SHA-256:
`db0f4ce9e54b59070c34d9aa81767b5e228bc2661db05b5fdd975af97b60496c`

개인 PKCS12 키와 암호는 공개 저장소에 절대 올리지 마세요. 이후 업데이트에도 같은 키를 유지해야 합니다.
